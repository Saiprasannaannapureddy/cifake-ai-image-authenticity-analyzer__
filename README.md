# AI Image Authenticity Detector

## 📌 Project Overview

AI-generated images are becoming more realistic and difficult to identify manually. This project develops a deep-learning-based system that classifies an image as either **Real** or **AI-Generated**.

The project uses a **Convolutional Neural Network (CNN)** trained using the **CIFAKE dataset**. A Flask-based web application allows users to upload an image and view the predicted result along with its confidence score.

---

## 🎯 Objectives

* Detect AI-generated and real images.
* Build a CNN-based binary image classification model.
* Provide an easy-to-use web interface for image prediction.
* Display the prediction confidence.
* Understand the application of deep learning for synthetic-image detection.

## 📊 Dataset

This project uses the **CIFAKE dataset**, which contains two categories of images:

* **REAL** – Real images
* **FAKE** – AI-generated images

The dataset is not included in this repository because of its large size.

Expected dataset structure:

```text
dataset/
├── train/
│   ├── REAL/
│   └── FAKE/
│
└── test/
    ├── REAL/
    └── FAKE/
```

## 🧠 Methodology

The system works through the following steps:

```text
Input Image
     ↓
Image Validation
     ↓
Image Preprocessing
     ↓
Resize & Normalization
     ↓
CNN Model
     ↓
Binary Classification
     ↓
Prediction + Confidence
```

### Image Processing

The uploaded image is:

1. Validated.
2. Converted to RGB format.
3. Resized to the model's required input size.
4. Normalized before prediction.

### Classification

The CNN analyzes visual features in the image and predicts one of two classes:

```text
REAL
or
AI-GENERATED
```

The application also displays the prediction confidence.

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/ai-image-authenticity-detector.git
```

### 2. Open the project folder

```bash
cd ai-image-authenticity-detector
```

### 3. Create a virtual environment

```bash
python -m venv venv
```

### 4. Activate the virtual environment

For Windows:

```bash
venv\Scripts\activate
```

### 5. Install dependencies

```bash
pip install -r requirements.txt
```

---

## ▶️ Run the Application

Start the Flask application:

```bash
python app.py
```

Then open the local address displayed in the terminal, usually:

```text
http://127.0.0.1:5000
```

Upload an image and the application will display the predicted class and confidence.

---

## 🏋️ Training the Model

If you want to train the model again, place the CIFAKE dataset in the required directory structure and run:

```bash
python train_model.py
```

The trained model will be saved in the `models/` directory.
